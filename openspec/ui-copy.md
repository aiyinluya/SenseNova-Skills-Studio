# UI 文案与语气（ui-copy）

> 原则：最少 chrome、有用 tooltip、禁止 Agent 黑话。实现为 `gr.Markdown`（`elem_classes=["sn-help"]`）或控件 `info=`。  
> 扩写展示：[ui-collapsible-prompt.md](./ui-collapsible-prompt.md)

## 语气

- **简洁**：一句说清，不超过 40 字（help 区可 2 行）
- **动作导向**：「生成」「探查」「搜索」— 不用「提交后台任务」「invoke skill」
- **状态**：进行中用「处理中…」「搜索中…」；成功用「✅」；失败用「❌」
- **禁止**：「请 Agent 继续」「check jobs tab manually」「submitted task id」（无结果时）

## 全局

| 位置 | 文案 |
|------|------|
| 配置横幅 | 🟢 API 配置就绪 / 🟡 … / 🔴 … |
| 操作 Toast | 最近一次操作的一句话摘要 |

## 参数帮助（必配）

### 图像 · 通用

- **扩写模式**：`auto`（默认，先评估再决定是否扩写）/ `force`（始终五段流水线）/ `disable`（原文直出图）。
- **扩写后的 Prompt**（Accordion 默认收起）：任务完成后展开查看；路径见 `result.expanded_prompt_path`。

### 图像 · 文生图

- **画面描述**：主体、风格、构图；中文建议写明需出现在图上的文案。
- **宽高比**：16:9 横屏、9:16 竖屏等。
- **Seed**：≥0 可复现；-1 随机。
- **负向描述**：可留空；默认叠加中文乱码/水印类负向词。

### 图像 · 信息图

- **内容与数据**：短主题会走完整 `sn-infographic` 版式分析。
- **最大生成轮次**：Studio 当前仅第 1 轮出图。

### 图像 · 系列 / 模仿 / 简历

- **系列**：首行风格块共享，每行单独扩写后出图。
- **模仿**：参考图识图 → 改写（非五段，见 OpenSpec）。
- **简历**：按简历海报版式扩写，竖版 9:16。

### PPT

- **模式 standard**：模板化排版，阶段脚本 `run_stage.py` 逐步执行。
- **模式 creative**：每页独立 PNG，耗时更长。
- **页数**：建议 8–15；过多会增加生成时间。

### 搜索

- **类别**：学术 / 代码 / 社交，对应不同 skill 脚本。
- **提供商**：如 arXiv、GitHub；部分社交源需 cookie，失败时见状态行。
- **条数**：1–30，过大可能超时。

### 深度研究

- **研究主题**：写入 `request.md` 标题，Agent 在 Cursor 中继续多轮调研。
- **范围说明**：时间、地域、对比对象等边界。

### 设置

- **SN_BASE_URL / SN_API_KEY**：在 `.env` 中配置，保存后自动热加载。

## 错误模板

```
❌ {简短原因}（详情见操作结果/日志）
```

不把整段 stderr 堆进 Toast；完整日志放在 Tab 内 Textbox（≤2000 字截断）。
